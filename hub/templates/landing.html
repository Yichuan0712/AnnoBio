Browser workspace · Windows · macOS

One workspace for the complete biomedical annotation workflow.

Bring research records into explicit pipelines, evaluate their outputs, improve Prompts with human oversight, and carry the resulting workflow into a reproducible Python project.

01 / PIPELINE

Build portable, reproducible pipelines

Combine Datasets with Generate steps, Process code, branches, and merges. Preserve execution history, save portable projects, and export selected routes as runnable Python projects.

02 / AGENT

Build through conversation

Describe the scientific task in natural language. The Agent proposes Prompts, mappings, nodes, and revisions for you to inspect and approve.

03 / CONNECT

Connect biomedical evidence

Search and import records from PubMed, ClinicalTrials.gov, ChEMBL, Europe PMC, OpenAlex, UniProt, bioRxiv, and medRxiv while preserving identifiers and source metadata.

04 / OPTIMIZE

Optimize and version Prompts

Use targeted editing, local search, reflective evolution, and few shot optimization. Automate revisions or keep a human in the loop to inspect and approve each new Prompt version.
